# WS2812B IR LED Controller

Модульная прошивка для управления адресной светодиодной лентой **WS2812B** с помощью **ИК-пульта (NEC)** на базе **Arduino Micro** (PlatformIO).

Проект оптимизирован для плавной работы анимаций с защитой от помех при приёме ИК-сигнала, включает CRT-коррекцию яркости (человеческое восприятие) и набор процедурных генеративных эффектов.

---

## Основные возможности

- **10 встроенных эффектов:**
  - `Rainbow` — динамическая интерполяция градиентного спектра;
  - 8 уникальных вариантов процедурной «плазмы» на базе математических синусоид (`beatsin8`, `sin8`) и кастомных палитр;
  - `Confetti` — плавное затухание со случайными вспышками.
- **Режим сплошного цвета (Solid Color):**
  - Быстрое переключение одной кнопкой.
  - Плавная регулировка оттенка (Hue) во всем спектре 0–255.
- **Гамма/CRT-коррекция яркости:**
  - Логарифмическая таблица пересчёта (256 значений в `PROGMEM`) обеспечивает визуально линейное изменение яркости.
- **Умное управление ИК-пультом (NEC):**
  - Поддержка одиночных нажатий и плавного изменения при **удержании кнопок** (Hold repeat) для яркости и цвета.
  - Аппаратная защита: кадр ленты не рендерится в момент приёма ИК-пакета (`Remote::isIdle()`), что устраняет мерцание светодиодов из-за блокировки прерываний библиотекой FastLED.
- **Модульная ООП-архитектура:** чистый C++ код с разделением логики по статическим классам без лишних аллокаций памяти.

## Аппаратные требования и подключение

### Компоненты:
1. **Плата:** Arduino Micro (или совместимая на ATmega32U4 / ATmega328P).
2. **Лента:** Адресная светодиодная лента WS2812B / NeoPixel (по умолчанию: **155 светодиодов**).
3. **ИК-приемник:** TSOP38238 / VS1838B (38 кГц, протокол NEC).
4. **Блок питания:** 5V с током, достаточным для вашего количества диодов (~60 мА на диод при 100% белом цвете).
5. **Резистор:** 300–500 Ом (на линию данных ленты, рекомендуется).
6. **Конденсатор:** 1000 мкФ 6.3V+ (параллельно питанию ленты, рекомендуется).

### Схема подключения:

| Компонент | Пин компонента | Пин Arduino Micro | Примечание |
| :--- | :--- | :--- | :--- |
| **WS2812B** | DIN (Data In) | **Pin 6** | Через резистор 300–470 Ом |
| **WS2812B** | 5V / GND | 5V / GND | Питание напрямую от БП 5V |
| **IR Receiver** | OUT / DATA | **Pin 2** | Цифровой пин |
| **IR Receiver** | VCC / GND | 5V / GND | Питание платы |

## Управление с пульта

Стандартная раскладка кнопок ИК-пульта:

| Кнопка | Действие | Особенности |
| :---: | :--- | :--- |
| **`OK`** | Включение / Выключение (Power Toggle) | Гасит ленту с очисткой буфера |
| **`UP`** | Увеличить яркость | Поддерживает зажатие / включает питание |
| **`DOWN`**| Уменьшить яркость | Поддерживает зажатие / включает питание |
| **`LEFT`**| Предыдущий эффект | Циклический переход |
| **`RIGHT`**| Следующий эффект | Циклический переход |
| **`1` – `9`** | Прямой выбор эффекта (0–8) | Мгновенно отключает режим одного цвета |
| **`0`** | Переключение в режим сплошного цвета | Вкл / Выкл Solid Color |
| **`*`** | Сдвиг цвета вперед (+Hue) | Поддерживает зажатие (быстрый перебор) |
| **`#`** | Сдвиг цвета назад (-Hue) | Поддерживает зажатие (быстрый перебор) |

## Настройка проекта

Все основные параметры вынесены в заголовочные файлы:

### `Config.h`
- `COUNT_LED` — количество светодиодов на вашей ленте (по умолчанию: `155`).
- `WS2812B_PIN` — пин управления лентой (по умолчанию: `6`).
- `IRREMOTE_PIN` — пин ИК-приемника (по умолчанию: `2`).
- `DEFAULT_BRIGHT` / `MINIMUM_BRIGHT` / `MAXIMUM_BRIGHT` — диапазон яркости (по таблице CRT).
- `HOLD_TIMEOUT` / `HOLD_INTERVAL` — задержка перед автоповтором (мс) и скорость автоповтора зажатой кнопки.

### `Keycodes.h`
Если ваш пульт отправляет другие hex-команды протокола NEC, просто переназначьте их в `Keycodes.h` под ваш пульт.

## Сборка и прошивка

### Использование PlatformIO (VS Code):
1. Установите расширение **PlatformIO IDE** в VS Code.
2. Клонируйте репозиторий или откройте папку проекта.
3. Подключите Arduino Micro к компьютеру через USB.
4. Нажмите кнопку **PlatformIO: Upload** (стрелка в нижней статусной строке) или выполните команду:
   ```bash
   pio run --target upload
   ```

Все зависимости (`FastLED`, `IRremote`) загрузятся автоматически согласно `platformio.ini`.
